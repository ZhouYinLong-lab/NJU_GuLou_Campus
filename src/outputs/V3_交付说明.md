# 南京大学鼓楼校区 · V3 模型与标注

本轮交付为 Blender 模型、静态审阅图和离线交互查看器。尚未进入视频制作。

## 已完成

- 保留并细化北大楼；依据南京大学档案中的图纸和照片，分别重建东大楼、西大楼、大礼堂、校史博物馆、小礼堂、西南楼和东北楼。增加屋面层次、瓦垄、檐口、窗框、门厅、台阶等外观细节。
- 校园建筑轮廓沿用官方 2024 年地图；普通建筑补充窗带、层间线、阳台和少量屋顶设施。
- 调整校园展示底座，补充道路、庭院铺装、乔木、长椅、灯杆、运动场围栏和看台，清理球场及大礼堂入口的树木遮挡。
- 添加 101 处可查询名称；重点建筑附参考来源。剔除十处地图文字提取产生的拼接或残缺名称。
- 六组静态图：全校鸟瞰、历史建筑群、博物馆与图书馆、南园、校园总图、大礼堂近景。每组提供干净图与标注图。

## 使用

`NJU_Gulou_Campus_V3.blend` 用 Blender 4.5 或更新版本打开，建筑分组可编辑，所用字体已打包。

`NJU_Gulou_Viewer.html` 用桌面版 Chrome / Edge 打开。文件内包含模型和脚本，无须联网或启动服务器。拖动旋转、滚轮缩放、右键平移；底部切换分区；右上角搜索建筑或切换标注。完整模型内嵌使 HTML 文件较大，首次打开需短暂加载。

`NJU_Gulou_Campus_V3.glb` 为通用模型交换文件。它保留几何和基础材质；Blender 程序化砖纹、渲染灯光与网页实时光照并非完全相同。静态 PNG 是 Blender 渲染质量的基准。

## 与参考视频的对应关系

目前已经具备校园微缩模型、统一灰绿配色、全校总览、分区放大、重点建筑细节和清晰名称标注；交互版可以旋转和缩放。这些是后续制作同类校园展示视频所需的模型和图面基础。当前交付中没有运镜片段、剪辑、音乐或成片。

## 精度范围

这是依据地图、图纸和照片制作的展示级外观模型。八处重点建筑有独立外观细化，普通教学楼和宿舍仍采用简化立面；没有进行摄影测量、现场测绘或逐窗核验。地图到模型的尺度为近似换算。底座是展示裁切形状，不能作为校园产权边界。植被、路面宽度及部分小设施具有表达性调整。
