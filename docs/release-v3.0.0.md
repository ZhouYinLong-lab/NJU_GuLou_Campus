# v3.0.0 — Blender campus model and offline viewer

首个公开版本，提供南京大学鼓楼校区的展示级 Blender 模型、通用 GLB、离线查看器、源码和视频预览。

## Included

- Editable Blender campus scene
- Video-render preparation scene
- GLB export
- Standalone offline HTML viewer
- Static review images and video preview
- Procedural modeling and validation scripts

## Scope

模型依据公开地图、校史档案和校园照片制作，属于展示级近似重建，不是官方数字孪生或测绘成果。第三方参考资料按其原始权利和许可执行。

完整资产包以 3 个 7-Zip 分卷发布：下载 `NJU_GuLou_Campus_v3.0.0_complete.7z.001`、`.002`、`.003` 到同一目录，然后用 7-Zip 打开 `.001` 解压。三卷必须同时保留。
